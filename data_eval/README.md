# data_eval/

Evaluation suites for the paper (arXiv v1, tag `paper-v1`). The paper's three tasks are evaluated on 160 items each.

## Frozen suites used in the paper

| File | Items | Role |
|---|---|---|
| `track1_extraction.jsonl` | 160 | Extraction task (ticker, section, filing_date) |
| `track1_json.jsonl` | 160 | json task (structured tool call) |
| `track1_router.jsonl` | 160 | Router task (5-label classification) |
| `track1_extraction_controlC.jsonl` | 160 | Control C (rejected-register paraphrase) for the extraction items. Used only in the preliminary nf4 probe on seeds 0 and 1, not in the confirmatory run (paper Section 4.4). Generated by `data_prep/gen_control_C.py`. |

These files must not be modified. Gold labels are fixed by construction (`data_prep/`); hygiene checks are in `audit_eval_suite.py` and `results/hygiene_audit/`.

## Kept for provenance (not used for the paper's results)

The `.bak` files document how the suites were built (paper Appendix C.3: expansion from 80 to 160 items; router label adjudication by GPT-4o, `data_prep/adjudicate_router.py`). Their relationship to the frozen suites, checked on 2026-11-04:

| File | Items | Contents relative to the frozen suite |
|---|---|---|
| `track1_extraction.n80.bak` | 80 | The 80-item suite before expansion (`data_prep/expand_eval.py`). All 80 records appear unchanged in `track1_extraction.jsonl`. |
| `track1_json.n80.bak` | 80 | The 80-item suite before expansion. All 80 records appear unchanged in `track1_json.jsonl`. |
| `track1_router.preadjudication.bak` | 80 | 80-item router snapshot named as pre-adjudication. All 80 prompts appear in `track1_router.jsonl` with the same gold label; only `item_id` numbering differs. |
| `track1_router.n80.bak` | 80 | 80-item router snapshot. Same 80 prompts and gold labels as `track1_router.preadjudication.bak`, in a different order; only `item_id` numbering differs from `track1_router.jsonl`. |
| `track1_router.n160_preadj.bak` | 160 | 160-item router snapshot named as pre-adjudication. Byte-identical to `track1_router.jsonl`. |

## Other files

| File | Items | Role |
|---|---|---|
| `track1_binary.jsonl` | 80 | Review task (COMPLETE / NEEDS_FOLLOW_UP) from an earlier design phase; not one of the paper's three tasks. Generated by `data_prep/gen_track1_eval.py`. |
| `track1_binary_smoke.jsonl`, `track1_json_smoke.jsonl` | 5 each | Small slices for pipeline smoke tests. |
